What this is

The Build Log is where I write about things I'm actually building — hardware projects, Python libraries, backend systems, and the occasional opinion on how software should work. No fluff, no engagement-bait, just notes from the workbench.

I'll be writing about the decisions, mistakes, and architecture of each of these as they evolve.

Why no CMS?

Because the simplest thing that works is a posts/index.json file and a folder of HTML files. No database. No cold starts. No Render free tier timeouts. Just GitHub Pages.

The best infrastructure is the one you don't have to think about.
